## 3. Advanced Anti-Cheating Security

### 3.1 Fullscreen Lockdown System
**Mandatory Fullscreen Enforcement**
- Automatic fullscreen entry on exam start
- **Exit Detection & Blocking**: Exam instantly pauses if student exits fullscreen
- **Violation Tracking**: Each attempt logged with duration outside fullscreen
- **Progressive Warnings**: Visual violation counter increases pressure
- **Forced Re-entry**: Manual confirmation required to resume

**Technical Controls**
- ESC key blocking and logging
- F11 fallback for browser compatibility
- Multi-vendor fullscreen API support
- Violation timer display (seconds outside fullscreen)

### 3.2 Tab & Window Monitoring
**Multi-Layer Detection**
- **Tab Switching Detection**: Alerts when student accesses other browser tabs
- **Window Blur Events**: Logs when exam window loses focus
- **Application Switching**: Detects Alt+Tab and window manager changes
- **URL Change Monitoring**: Prevents navigation to external resources

**All violations logged with:**
- Exact timestamp
- Duration of distraction
- Frequency analysis
- Automatic administrator alerts

### 3.3 Keyboard & Input Controls
**Disabled Functions**
- Right-click context menu blocked
- Copy/paste prevention (Ctrl+C, Ctrl+V, Ctrl+X)
- Developer tools disabled (F12, Ctrl+Shift+I)
- View source blocked (Ctrl+U)
- All blocked attempts logged for review

### 3.4 Multiple Monitor Detection
- Automatic detection of extended displays
- Warnings issued for multi-screen configurations
- Logged for manual administrator review

**Business Impact**: Creates exam conditions **more secure than traditional paper exams**, where students could hide notes or devices. Digital monitoring is continuous and comprehensive.
